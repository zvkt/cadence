how to use cadence

Cadence is a focus stopwatch with optional breaks, task lists, and a local focus history. The app works without an account or third-party services.

work and breaks

  • Select start to begin the work stopwatch, pause to stop it, or reset to start over.
  • Select start break whenever you want a break. Its length is the accumulated work time divided by the work-to-break ratio in settings. You can pause, resume, or end a break early.
  • When a break ends, work starts automatically if that setting is enabled.
  • The optional task trigger starts a break when you complete a top-level task or finish its last open subtask. The subtask trigger starts one when you complete a nested task or finish its last open subtask. Completing items only because you checked their parent does not trigger a break. Triggers are skipped if a break is already running or no work time is logged.

tasks

  • The to-do list is optional. Add tasks and descriptions, create multiple lists, and rename a list.
  • Use each task's edit action to change its name or description. Add subtasks from the task actions; collapse a task to hide its subtasks.
  • Delete a task from its actions. Deleting a task that has subtasks requires a second confirmation. Completed tasks can be cleared together from the bottom of the list.
  • Drag the grip to reorder a task. Drop near the middle of another task to make it a subtask; drop above or below to reorder it.
  • On touch screens, swipe right to nest a task under the task above it, or swipe left to move it out one level.
  • Keyboard alternatives: focus a task's grip and use the arrow keys to reorder or change its nesting. Ctrl+Tab nests under the previous task; Ctrl+Shift+Tab moves out. Press Escape to cancel a drag.
  • Completing a task also completes its subtasks. A completed parent reopens if one of its subtasks is unchecked. Use clear completed to remove completed tasks.

settings

  • Work : break ratio sets how much work time is needed for one unit of break time. For example, a ratio of 5 gives 1 minute of break for every 5 minutes of work.
  • Auto-start work starts the stopwatch when a break finishes.
  • Start break when a task/subtask is completed enables the matching completion trigger described above.
  • Use military time displays session times in 24-hour HHmm format.
  • Log elapsed time when resetting includes a running session in history when you reset the stopwatch.

focus history

Pausing records a work session. Resetting records it only when the matching setting is enabled. Sessions that cross midnight are split across the days they cover. The activity chart summarizes the last 365 days; daily totals omit days without focus time. Delete an individual session from the session list if it was recorded by mistake.

offline use and saved data

Cadence uses browser storage for settings, task lists, and focus sessions. This data stays in the current browser and is not synced or backed up. Clearing browser data removes it.

When served from HTTPS or localhost, the app caches its pages and assets after the first visit so you can reopen it offline. If you open the files directly from your device, the app also works offline, but browser service workers are not available for that file URL.

Timer sounds are generated locally by the browser's Web Audio API. The browser may require a user gesture before playing sound.
